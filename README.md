# 手機剪短影音（Claude 雲端版範本）

用手機拍片、用手機叫 Claude 剪，剪好用手機下載。全程不用開電腦。

成品規格：直式 1080×1920、59 秒內、稍微加速、下方有字幕和說話者小字卡，適合 FB／IG／Reels。

## 你需要

- Claude **Pro 或 Max** 方案（雲端版 Claude Code 要這兩種方案才有）
- GitHub 帳號（免費的就可以）
- Google 帳號（素材和成品放在你自己的 Google 雲端硬碟）

## 一次性設定（約 15 分鐘，都用手機）

### 1. 複製這個範本

1. 手機瀏覽器打開這個 repo 頁面，按綠色的 **Use this template → Create a new repository**。
2. 名稱隨便取，例如 `my-video`。
3. **一定要選 Private（私人）**，因為之後成品可能會放在裡面。
4. 按 Create repository。

### 2. 讓 Claude 連上 GitHub

1. 打開 Claude App → 下方的 **Code** 分頁（或用手機瀏覽器開 claude.ai/code）。
2. 第一次會要你連結 GitHub，照畫面授權，允許它讀取剛剛建的 repo。

### 3. 建立雲端環境

在 Code 分頁選 repo 的地方，找到「環境」（Environment）設定，新增一個環境：

- **網路權限（Network access）**：選 **Full（完整）**。剪片要下載語音辨識模型和字型等工具，選其他的可能會失敗。
- **安裝腳本（Setup script）**：打開這個 repo 的 [`cloud/setup.sh`](cloud/setup.sh)，按 Raw，整份複製貼進去。
  - 沒貼也能用，只是每次開新對話第一次會多等 3～5 分鐘自動安裝。
- 環境變數先空著，第 4 步會用到。

### 4. 連上你的 Google 雲端硬碟

1. 用剛剛的 repo＋環境開一個新對話，打：**設定雲端硬碟**
2. Claude 會給你一個 Google 登入網址，用手機打開、登入、按「允許」。
3. 接著瀏覽器會顯示「無法連線」或「找不到網頁」，**這是正常的**。把網址列那一整串網址（`http://127.0.0.1:53682/` 開頭）複製，貼回給 Claude。
4. Claude 會回你一行 `GDRIVE_TOKEN_B64=……`。到第 3 步的環境設定，把整行貼進「**環境變數**」存檔。
   - 這行等於你雲端硬碟的鑰匙，**不要給別人、不要貼到其他地方**。
   - 存好之後，以後每次開對話都會自動連上雲端硬碟。

### 5. 在雲端硬碟建資料夾

在 Google 雲端硬碟 App 建兩個資料夾：**影片素材**、**影片成品**。

## 每次剪片

1. 手機拍好片，用 Google 雲端硬碟 App 上傳到「影片素材」底下的一個新資料夾，例如「影片素材/咖啡廳試喝」。
2. 在 Claude App 的 Code 分頁，用同一個 repo 和環境開新對話，跟它說：

   > 剪這支：素材在「影片素材/咖啡廳試喝」，成品放「影片成品」。主角不用標名字，畫外問問題的人標「攝影師」。

3. Claude 會：複製素材 → 轉逐字稿 → **請你確認字幕** → 剪輯輸出 → 檢查畫面 → 放回「影片成品」。
4. 打開 Google 雲端硬碟 App →「影片成品」→ 下載到手機，就能發佈。

要改字幕就直接說「第 8 秒那句改成……」，它會出 `v2`，不會蓋掉舊版。

### 不想用雲端硬碟拿成品？

跟 Claude 說「成品用 GitHub 給我」。它會把影片放進你這個私人 repo 的「成品」資料夾，給你一個連結，手機打開按下載就好（單檔要小於 100MB，59 秒的片通常 20～40MB）。

## 常見問題

- **等很久？** 一支 1 分鐘的片，從開始到出片大約 10～20 分鐘。第一次用會多下載語音模型（約 1.6GB）。
- **雲端硬碟授權失效？** 再說一次「設定雲端硬碟」，把新的那行換掉舊的環境變數。
- **原片會不會被刪？** 不會，雲端硬碟上的原片只會被複製。
- **配樂**：要加的話，請用確定可以商用的音樂。

## 檔案說明

- `.claude/skills/short-video-edit/`：剪片流程和腳本
- `cloud/setup.sh`：雲端環境安裝腳本
- `cloud/ensure.sh`：每次開對話自動檢查工具、接上雲端硬碟
- `CLAUDE.md`：給 Claude 的工作規則
